## I. 요구사항 분석

### 원 요구
- 한국산업인력공단 '청렴훈련 캠페인'을 KEESS 에 게재
- 게재 형식 제한 없음 (사이트 내 게재로 충족), 추가 확인 절차 없음

### 의도 해석
**[R1] 캠페인 게재**
- 표면 요청: 멀티캠퍼스처럼 캠페인을 게재
- 진짜 의도: 훈련기관으로서 부당영업을 하지 않는다는 청렴 의지를 이용자에게 공개
- 해결 문제: 현재 사이트에 청렴·부당영업 금지 메시지 없음
- 성공한 모습: 이용자가 사이트에서 캠페인 메시지를 확인하고, 필요하면 바로 신고로 이어짐

**[R2] 기존 흐름과의 정합**
- 진짜 의도: 부정훈련 예방·신고 흐름 안에 캠페인을 자연스럽게 배치 (새 팝업으로 홈 방해 금지)
- 성공한 모습: 기존 모달 3개 탭은 그대로, 캠페인 탭만 추가

**[R3] 자사 메시지 정합 (암묵)**
- 진짜 의도: 캠페인 핵심인 '법정의무교육 강요·끼워팔기 금지' 와 자사 법정필수·인재키움 문구가 충돌하지 않게
- 성공한 모습: 자사 페이지에 끼워팔기로 오해될 표현 0

### 기능 매핑
| 요구 | 기능 |
|---|---|
| R1 | **IC1** 모달 제목 변경, **IC2** 캠페인 탭, **IC3** 캠페인 비주얼 |
| R2 | **IC4** 진입점·기본 탭, **IC5** 신고 연결 |
| R3 | **IC6** 자사 카피 점검 |
| 품질 | **IC7** 반응형·접근성·회귀 검수 |

## II. 성공 기준
- 모달을 열면 캠페인 탭이 첫 화면으로 보임
- 기존 예방안내·신고 접수·신고 조회 탭의 DOM·동작 변화 0
- PC·태블릿·모바일(360 포함) 문구 판독 가능, 가로 스크롤 0
- 자사 카피에 끼워팔기 오해 표현 0

## III. 사용자와 흐름
- 사용자: 기업 HR 담당자, 훈련 참여자, 일반 방문자
- 흐름
```
푸터 '청렴훈련 · 부정훈련 예방' → 모달 [청렴훈련 캠페인] 탭 (기본)
                                   └ '신고 접수로 이동' → [신고 접수] 탭
푸터 '부정훈련 신고' → 모달 [신고 접수] 탭 (기존 동작 유지)
```

### IC1 모달 제목
- '부정훈련 예방 및 신고' → '청렴훈련 · 부정훈련 신고'
- 완료: 제목 변경, 모달 aria-labelledby 연결 유지

### IC2 청렴훈련 캠페인 탭
- 탭 이름: 청렴훈련 캠페인 (첫 번째)
- 구성 (위에서 아래)
  1. 캠페인 비주얼 (IC3) + 캡션 `한국산업인력공단 청렴훈련 캠페인`
  2. 태그 `#건강한 훈련문화`
  3. 제목 `캠페인 청렴훈련`
  4. 핵심 문구 `법정의무교육은 강요하지 않습니다.`
  5. 대비 칩 2개: `부당영업 NO` (회색 계열 + 금지 아이콘) / `청렴훈련 YES` (P4 옅은 면 + 체크 아이콘)
  6. 하단 문구 `청렴훈련 캠페인은 한국산업인력공단과 함께 합니다.`
  7. 신고 연결 (IC5)
- 톤: 긍정·정돈. 기존 예방안내 탭의 빨강 경고 박스 스타일 사용 금지
- 완료: 7개 요소 표시, 모든 문구 HTML 텍스트

### IC3 캠페인 비주얼
- 소스: 청렴훈련 캠페인 게재 배너(1920×384)의 **일러스트 영역만** 자른 이미지 (730×328)
  - 제공 파일: `integrity-campaign-visual.png`, `integrity-campaign-visual.webp`
  - 배너 좌측 글자 영역, 타 기관 팝업 틀은 포함하지 않음
- 원본 훼손 금지: 크기 조정 외 색·문구·배치 변경 금지, 확대 금지 (표시 폭 ≤ 730px)
- 대체 텍스트: `캠페인 청렴훈련, #건강한 훈련문화, 부당영업 NO, 청렴훈련 YES`
- 완료: 레이아웃 흔들림 없음(너비·높이 지정), 깨진 이미지 시 대체 면

### IC4 진입점·기본 탭
- 푸터 '청렴훈련 · 부정훈련 예방' 클릭 → 캠페인 탭으로 열림
- 푸터 '부정훈련 신고' 클릭 → 신고 접수 탭으로 열림 (기존 유지)
- 그 밖에 코드상 모달을 여는 곳이 있으면 기존 목적 탭 유지
- 완료: 두 진입점 각각 기대 탭으로 열림

### IC5 신고 접수 연결
- 문구 `부당영업·부정훈련을 알고 계신가요?` + 버튼 `신고 접수로 이동`
- 동작: 신고 접수 탭 활성화 + 탭 패널 상단으로 포커스
- 완료: 키보드·마우스 모두 동작, 탭 상태·aria-selected 갱신

### IC6 자사 카피 점검
- 대상: 홈, /content (법정 허브), /kium, 인재키움 관련 데이터
- 금지 패턴: 법정교육 '무료 제공·증정·서비스·끼워' 가 환급·정부지원 과정 도입 조건과 결합된 표현
- 결과: 해당 0건 확인 또는 발견 목록 보고 (수정은 보고 후 결정)

### IC7 반응형·접근성·회귀
- 9개 폭 가로 스크롤 0, 탭 4개가 360 에서 깨지지 않음
- 탭 키보드 동작은 기존 방식과 동일
- 대비: 본문 4.5:1, 아이콘 3:1
- 기존 3개 탭 DOM 변경 0, 신고 접수·조회 기능 회귀 0
