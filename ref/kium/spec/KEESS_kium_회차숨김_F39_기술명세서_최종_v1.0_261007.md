## 3. 구현 사양 (`lib/kium/sessions.ts`)

| # | 변경 |
|---|---|
| 1 | `KiumSession`에 `hidden?: true` 필드 추가 (주석: 폐강은 삭제, 숨김은 플래그) |

- 모든 소비처(일정·스트립·상세 회차·카운트·`getSessionById` 딥링크·`isOpenCourse`)는 기존대로 `KIUM_SESSIONS`만 참조 → 컴포넌트 수정 0

- 숨김 해제: 해당 행의 `hidden: true` 삭제 한 줄
