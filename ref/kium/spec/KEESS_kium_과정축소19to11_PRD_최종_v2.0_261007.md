## 1. 배경 · 문제 정의

- 사업 결정: 2026 인재키움 프리미엄 운영 과정 19 → 11 확정
- 미운영 과정이 남을 때 리스크
  - 신청·상담 유입 후 "운영하지 않는 과정" 응대 → 신뢰 하락
  - 오제공 0 원칙(/kium 운영 원칙) 위배
- 단순 삭제로 끝나지 않는 구조 영향
  - 분야 2종(승진자 · 비즈니스 역량) 0건 → 전체 보기에 `승진자 0` 빈 칩 노출 (현 코드는 전체 보기 0건 분야를 거르지 않음)
  - 공개교육 회차 5건 동반 소멸 → 일정표·스트립·기간 칩 수치 변동

## 4. UX 원칙 (시니어 UI/UX 판단)

1. **삭제는 흔적 없이**: 사용자에게 "축소됨" 안내 배너·취소선·준비중 카드 노출 안 함. 홍보 사이트에서 미운영 상품의 흔적은 탐색 비용만 늘림
2. **빈 선택지 금지**: 결과 0건이 확정된 칩은 처음부터 만들지 않음 (Hick 법칙: 선택지 7 → 5로 판단 비용 감소)
3. **시각 정체성 고정**: 잔여 분야의 색(dot·썸네일 메시)과 순서 감각 유지. 색 재배정 금지 → 재방문자의 학습 유지
4. **수치는 전부 파생**: 화면 숫자는 데이터 배열에서만 계산. 수기 숫자 0
5. **링크 무결성**: 과정 ID 재번호 금지. 죽은 딥링크는 조용히 기본 화면으로 (에러 토스트 없음)
6. **카피 불변**: 잔여 과정과 사업소개 카피 수정 없음. `직급과 직무, 조직의 필요에 맞는 교육과정` 문구는 신입·팀장·임원 과정이 남아 사실 유지 (검토 완료)
