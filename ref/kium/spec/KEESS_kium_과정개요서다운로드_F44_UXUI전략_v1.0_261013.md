## 2. 사용자 · 맥락

- 주 사용자: 중소기업 HR·교육 담당자 (사내 보고·결재용 자료 필요)
- 보조 사용자: TM·영업, 공동마케팅 파트너(아뱅) → 링크 공유 후 자료 수령
- 과업: 과정을 훑어본 뒤 "내부 공유용 자료"를 받는다 → 탐색 맥락 안에서 발견되어야 함
- 문서 성격: 11개 과정 전체 개요 (특정 과정 단위 아님) → 목록 단위 위치가 맞음

### 채택안 A 배치 규칙
- PC·태블릿: 세그먼트(전체과정 / 공개교육) 좌측, 다운로드 링크 우측 정렬 (`justify-content:space-between`)
- 모바일(행 폭 부족): 세그먼트 아래 줄로 줄바꿈, 좌측 정렬 · 터치 영역 44px 유지
- 두 보기(전체과정 · 공개교육) 공통 노출, 보기 전환 시 위치 고정
- 상세 필터(모집 상태)보다 위 → 필터 조작과 시선 충돌 없음
