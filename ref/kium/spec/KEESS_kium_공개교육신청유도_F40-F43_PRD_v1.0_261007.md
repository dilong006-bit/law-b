|---|---|
| 작성 | 2026-10-07 · HRD사업지원팀 임지홍 |
| 요청 | HRD사업팀 지예정 대리 (9/21 미팅 4개 항목) · 기획 태스크 27444 |
| 대상 | law-b.vercel.app (`/` 홈 · GNB · `/kium`) |

| 연계 | 리서치 「KEESS 인재키움 공개교육 신청 유도 UI/UX 리서치」 · 전략 「KEESS 인재키움 공개교육 신청 유도 빌드·배포 전략」 |

## 1. 문제 · 목표

| 구분 | 내용 |
|---|---|
| 문제 | 공개교육(1명부터 신청) 존재가 첫 화면에서 드러나지 않음 · 홈 인재키움 슬라이드는 정부지원 설명형 · /kium 상단 버튼이 신청 행동과 무관(지원대상 확인) |
| 목표 | 홈 첫 장 · GNB · /kium 상단 3개 접점에서 「공개교육 신청」 동선을 1클릭으로 연결 |
| 성공 지표(GA) | `hero_kium_open` 클릭 · `kium_hero_open` 클릭 · 공개교육 회차 상담 제출 수 · 첫 장별(법정/공개교육) 클릭률 비교 |

## 2. 사용자 · 시나리오

| 사용자 | 시나리오 |
|---|---|
| 중소기업 HR 담당자 | 홈 진입 → 첫 장 공개교육 → [공개교육 신청] → /kium 공개교육 회차 목록 착지 → 회차 [상담하기] |
| /kium 직접 진입 | 상단 [공개교육 신청하기] → 같은 페이지 공개교육 회차 목록 이동 |
| 자료 먼저 보는 담당자 | [과정 소개서 받기] → PDF 즉시 다운로드(폼 없음) · 개정본 수령 후 노출 |

## 3. 기능 요구사항 (MoSCoW)

| ID | 우선 | 요구사항 | 수용 기준 |
|---|---|---|---|
| F40-1 | Must | 홈 히어로 정부지원 슬라이드 → 공개교육 슬라이드 교체 | 원고 3종(메인 · 서브 · 버튼) 원문 일치 |
| F40-2 | Must | C안: 접속마다 법정 · 공개교육 첫 장 교차 | 첫 방문 50:50 · 재방문 교차 · 깜빡임 0 · 하이드레이션 경고 0 |
| F40-3 | Should | 태그 옆 「다음 개강 11.2(월)」 자동 표기 | 회차 데이터 기준 · 지난 회차 자동 제외 · 0건이면 숨김 |
| F40-4 | Should | 보조 링크 [인재키움 프리미엄 알아보기] → /kium | 정부지원 설명 진입 경로 유지 |
| F40-5 | Must | 키보드 포커스 시 자동 넘김 정지 | WCAG 2.2.2 |
| F41-1 | Must | GNB 칩 확대 | 글자 14px · 높이 36px · 1024~1440 메뉴 1줄 유지 |
| F41-2 | Must | 반짝임 강조 + 정지 | 진입 후 2회(4.8초) 정지 · 모션 줄이기 시 없음 |
| F42-1 | Must | 과정 소개서 다운로드(폼 없음) | 홈 2차 버튼 + 과정안내 상단 2곳 |
| F42-2 | Must | 게시 스위치 | 개정본 전 `ready=false` → 버튼 DOM 0 |
| F43-1 | Must | /kium 상단 CTA 교체 | 1차 [공개교육 신청하기] · 2차 [문의하기] |
| F43-2 | Must | 1차 동작 | 과정안내 탭 + 공개교육 보기 전환 후 목록 위치 이동 |
| F43-3 | Should | 딥링크 착지 | `/kium?tab=courses&mode=open` 진입 시 목록 위치 착지 |

### Won't (이번 범위 제외)
- 모바일 헤더 축약 칩(940px 이하): 기존 햄버거 NEW 배지 유지, 검토 시 옵션 제안
- FAQ 하단 [신청 문의] 라벨 변경 · FAQ 「10~12월 동일 과정 반복 개설」 문구
- 상담 폼 문의 유형 신설

## 4. 화면 명세

| 위치 | 변경 전 | 변경 후 |
|---|---|---|
| 홈 히어로 슬라이드 | 정부지원 · 「교육비 부담은 낮추고, 훈련비의 90~95%는 환급 받고」 · [자세히 보기] | 태그 `공개교육 · 다음 개강 11.2(월)` · 「필요한 직원만, 필요한 교육으로」 · [공개교육 신청] · 보조 링크 |
| 홈 슬라이드 순서 | 법정 · 브랜드 · 인재키움 · 예시 4 | 법정 ↔ 공개교육 1·2번 교차 · 브랜드 · 예시 4 (7장 유지) |
| GNB 칩(PC) | 13px · 32px · 7초 무한 반짝임 | 14px · 36px · 2회 후 정지 · hover/포커스 1회 |
| /kium 상단 | [신청 문의] · [지원대상 확인] | [공개교육 신청하기](채움) · [문의하기](외곽선) |
| 과정안내 상단 | 세그먼트만 | 세그먼트 + 오른쪽 [과정 소개서 받기 PDF] (스위치 on 시) |

- 카피 원문: 메인 `필요한 직원만, 필요한 교육으로` / 서브 `단 1명도 신청 가능한 공개교육으로 교육 운영의 부담은 낮추고, 필요한 역량은 바로 채워보세요.` / 버튼 `공개교육 신청`
- 줄바꿈만 추가: 메인 쉼표 뒤 · 서브는 PC만(760 이하 자연 줄바꿈)

## 5. 미확정 항목 처리 (상수 1줄 전환)

| 항목 | 현재 값 | 전환 방법 |
|---|---|---|
| C안 동의(지예정 대리) | `HERO_START='alternate'` | `'legal'` 법정 고정 · `'kium'` 공개교육 고정 |
| 정부지원 슬라이드 교체 | 교체 | `KIUM_OPEN_SLIDE` → `KIUM_GOV_SLIDE` 1곳 교체 |
| 과정 소개서 개정본 | `ready=false` | 파일 배치 · `sizeLabel` · `ready=true` |

## 6. 비기능 요구사항
- SSG 유지 · 서버/첫 클라이언트 마크업 동일(하이드레이션 경고 0)

- 터치 타깃 44px 이상 · 모션 줄이기 준수 · 가로 스크롤 0 (390 · 768 · 1024 · 1280 · 1440)
