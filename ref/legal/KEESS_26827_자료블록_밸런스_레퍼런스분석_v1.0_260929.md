# KEESS 26827 '카드뉴스와 과정소개서' 블록 밸런스 레퍼런스 분석 v1.0

- 작성: 2026-09-29 / HRD사업지원팀 임지홍 (시니어 UI/UX 관점)
- 대상: /content 법정 허브 자료 블록 (배포본 ea106b1, 1440 기준)
- 결론 먼저: **밸런스는 가능하다.** 문제는 요소 크기가 아니라 '세로형 이미지 1장 옆에 짧은 텍스트 카드 1장'이라는 **조합**이다. 조합을 바꾸면 해결된다.

---

## 1. 왜 안 맞는가 (구조 원인)

| 요소 | 성질 | 1440 실측 |
|---|---|---|
| 카드뉴스 | 4:5 세로 비율 고정. 폭이 정해지면 높이가 자동으로 커짐 | 폭 420 → 높이 525 (+컨트롤 56) = 581 |
| 과정소개서 카드 | 텍스트 3줄 + 버튼. 내용이 적어 높이가 작음 | 182 |
| 결과 | 높이 차 219%, 우측 빈 공간 41% | |

- 세로 비율 미디어는 폭을 줄여도 높이가 텍스트 카드보다 항상 큼 (폭 300이어도 375)
- 따라서 **크기 조절로는 해결 불가**, 다음 셋 중 하나가 필요
  1. 우측을 **의미 있는 콘텐츠로 채워** 높이를 맞춘다
  2. 두 요소를 **같은 행에 두지 않는다** (위아래 분리)
  3. 미디어의 **형태를 바꾼다** (1장 캐러셀 → 여러 장 가로 배열)

## 3. 해결 패턴 4가지 (비교)

### 패턴 A. 목차 동기화형 (권장)
> 캐러셀의 점을 **장별 제목 목차**로 바꿔 우측에 두고, 그 아래 소개서 카드를 붙인다.

```
┌──────────────┬──────────────────────────────────────┐
│              │  카드뉴스로 먼저 보기                  │
│   카드뉴스    │  ▶ 법정교육, 우리 회사는 몇 개나…  (선택) │
│   4:5 1장     │    교육만 열면 끝일까요?               │
│              │    2026 최신 법정필수교육, 한 곳에      │
│  (4열)        │    올해 법정교육, 지금 점검하세요       │
│              ├──────────────────────────────────────┤
│   < 1/4 >    │ [표지] 2026 법정필수교육 과정소개서      │
│              │        과정 구성·학습 목표·강사 [받기]   │
└──────────────┴──────────────────────────────────────┘
      4                         8
```
- 좌 4열: 카드뉴스 1장 (1440 약 367×459)
- 우 8열 (위): 목차 4항목. 누르면 좌측 카드 전환, 현재 장 강조. 각 항목 = 장 제목 + 1줄 요약
- 우 8열 (아래): 소개서 가로 카드 (작은 표지 + 제목 + 담긴 내용 + 버튼)
- 높이: 목차 약 300 + 소개서 약 160 + 간격 16 ≈ 476 vs 좌 459 + 컨트롤 → **±5% 안에서 맞춤 가능**
- 장점
  - 빈 공간이 사라지고, 우측이 '장식'이 아니라 **내비게이션 + 전환** 역할
  - 카드뉴스 문구가 HTML 텍스트로도 노출 → 이미지 속 글자를 못 읽는 사용자·검색·접근성 보완
  - 4장이 '오프닝 → 문제 → 솔루션 → 행동' 순서라 목차가 곧 이야기 구조
- 단점: 구현 요소 증가 (목차-카드 동기화)
- 모바일(880 이하): 카드뉴스 전폭(최대 420) + 다음 장 피크 스와이프 + 아래 현재 장 제목 1줄과 `1 / 4` → 소개서 카드 세로
- 유사 사례 유형: Stripe·Linear 등의 '기능 탭 + 미디어' 구성, 교육 플랫폼의 '챕터 목록 + 영상' 구성

### 패턴 B. 가로 갤러리 + 소개서 배너 (upgrade-02 안)
```
┌────────┬────────┬────────┬────────┐
│ 카드 1  │ 카드 2  │ 카드 3  │ 카드 4  │   각 4:5, 누르면 확대
└────────┴────────┴────────┴────────┘
┌─────────┬───────────────────────────────┐
│ [표지]   │ 과정소개서 · 담긴 내용 · [받기]  │
└─────────┴───────────────────────────────┘
```
- 장점: 4장이 한눈에, 캐러셀 불필요, 구현 단순, 행마다 높이가 자연히 맞음
- 단점: 블록 높이 증가 (약 330 + 260), 이미지 속 글자가 작아 PC에서도 확대해야 읽힘, 카드뉴스가 과하게 주인공이 됨
- 적합: 카드뉴스를 가장 강조하고 싶을 때

### 패턴 C. 소개서 주인공형
```
┌───────────────────────────┬───────────────┐
│ [큰 표지 목업]  과정소개서   │  카드뉴스 스트립 │
│  담긴 내용 · 미리보기 · 받기 │  (작은 4장 2×2) │
└───────────────────────────┴───────────────┘
```
- 장점: 전환(자료 받기)이 주 행동이라는 점에 충실
- 단점: 카드뉴스가 너무 작아져 존재감 약함, 2×2 썸네일 글자 판독 불가

### 패턴 D. 분리형 (가장 단순)
- 카드뉴스와 소개서를 각각 다른 행·블록으로 (카드뉴스 전폭 캐러셀 / 소개서 배너)
- 장점: 규칙 위반 원천 차단
- 단점: 캐러셀 좌우 빈 공간이 다시 생김, 높이 예산 불리

### 비교 표

| 기준 | A 목차 동기화 | B 가로 갤러리 | C 소개서 주인공 | D 분리 |
|---|---|---|---|---|
| 좌우 높이 균형 | ◎ (±5% 설계) | ◎ (행 분리) | ○ | △ |
| 빈 공간 | ◎ 없음 | ◎ 없음 | ○ | △ |
| 카드뉴스 가독성 | ◎ HTML 목차 병기 | △ 작게 4장 | ✕ | ○ |
| 소개서 전환 | ○ | ○ | ◎ | ○ |
| 블록 높이 (1440) | ◎ 약 480 | △ 약 620 | ○ 약 480 | △ 약 800 |
| 높이 예산(H×6) 영향 | 유리 | 보통 | 유리 | 불리 |
| 구현 난이도 | 중 | 하 | 하 | 하 |
| 최종본 교체 | 이미지 src·목차 문구 | 이미지 src | 이미지 src | 이미지 src |

**권장: 패턴 A.** 빈 공간을 기능으로 채우고, 높이 예산에도 가장 유리하며, 카드뉴스 문구를 텍스트로 노출해 접근성까지 해결한다.

## 4. 패턴 A 상세 설계

### 4-1. 레이아웃 (12열)

| 폭 | 구성 |
|---|---|
| 1041 이상 | 좌 4열 카드뉴스 / 우 8열 (목차 + 소개서) |
| 881~1040 | 좌 5열 / 우 7열 (목차 요약 1줄 숨김, 제목만) |
| 880 이하 | 세로: 카드뉴스(최대 420, 가운데, 피크 스와이프) → 현재 장 제목 + `1 / 4` → 소개서 카드 |

### 4-2. 목차 (우측 상단)
- 제목 h4: `카드뉴스로 먼저 보기`
- 항목 4개 (`role="tablist"` 또는 버튼 목록)

| 장 | 제목 | 1줄 요약 |
|---|---|---|
| 1 | 법정교육, 우리 회사는 몇 개나 끝냈나요? | 매년 챙겨야 할 법정교육 점검 |
| 2 | 교육만 열면 끝일까요? | 대상 선정부터 증빙까지 담당자의 일 |
| 3 | 2026년 최신 법정필수교육, 한 곳에 | 최신 콘텐츠 · 맞춤 구성 · 운영 지원 |
| 4 | 올해 법정교육, 지금 점검하세요 | 3가지 질문으로 필요한 과정 확인 |

- 현재 장: 좌측 P4 세로선 + 제목 --ink 굵게. 나머지는 --muted
- 숫자 번호 표시 금지 원칙 → 순서는 세로선·위치로만 표현
- 항목 높이 44px 이상, 키보드 위아래 이동
- 카드 이미지를 누르면 확대 보기 (라이트박스), 목차를 누르면 좌측 카드만 전환

### 4-3. 소개서 카드 (우측 하단)
- `.lg-box` 가로형: 좌 표지 썸네일(3:4, 폭 약 96px) / 우 제목·담긴 내용 3개(한 줄 칩)·`과정소개서 받기`
- 1차 버튼은 이 블록에서 이것 1개

### 4-4. 카드뉴스 (좌측)
- 4:5, 라운드 --r, shadow-1
- 하단 컨트롤: 이전 · `1 / 4` · 다음 (보이는 크기 작게, 터치 영역 44px)
- 자동 넘김 없음 (허브 안은 읽는 영역)
- 임시 실사 이미지 사용 중에도 목차 문구는 최종 원고 기준으로 노출

### 4-5. 높이 맞춤 규칙
- 행 `align-items: stretch`
- 우측 컬럼은 `display:flex; flex-direction:column`, 목차는 남는 높이를 나눠 가짐(`flex:1`), 소개서는 내용 높이
- 좌측 카드뉴스 폭이 높이를 결정 → 우측이 그 높이에 맞춰 늘어남
- 검증: 좌우 높이 차 ≤ 5%, 우측 콘텐츠 채움 ≥ 85%

## 5. 기존 계획(upgrade-01 커밋 12) 변경점

| 항목 | 기존 (패턴 B) | 변경 (패턴 A) |
|---|---|---|
| 카드뉴스 | 4장 가로 그리드 + 라이트박스 | 1장 + 목차 동기화 + 라이트박스 |
| 소개서 | 12열 배너 (4+8) | 우측 하단 가로 카드 |
| 행 구성 | 2행 | 1행 (4+8) |
| 데이터 | LEGAL_CARDNEWS src·alt | + 각 장 `title`, `summary` 필드 |
| 모바일 | 가로 스와이프 4장 | 1장 피크 스와이프 + 현재 장 제목 |
| 블록 높이 (1440) | 약 620 | 약 480 |

- 카드뉴스 최종본(10/12) 수령 시: 이미지 src + 목차 title·summary를 최종 원고로 교체
