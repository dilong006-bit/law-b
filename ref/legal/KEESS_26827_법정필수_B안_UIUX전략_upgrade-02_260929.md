## 0. 사례 진단: '카드뉴스와 과정소개서' 블록

배포본 1440 캡처 기준.

| 증상 | 수치·관찰 | 원인 |
|---|---|---|
| 좌우 높이 불일치 | 좌 카드뉴스 약 525px, 우 소개서 약 180px → 우측 하단 약 345px 공백 | 성격이 다른 두 요소를 같은 행에 배치 |
| 면적과 정보량 역전 | 섹션에서 가장 큰 면적이 **빈 자리표시** (내용 0) | 자리표시를 배포본에 노출 |
| 폭 기준 혼재 | 좌 420px 고정, 우 나머지 가변 → 가장 넓은 카드가 가장 정보가 적음 | 고정 px 열 사용, 그리드 비율 없음 |
| 카드 스타일 2종 | 좌 점선 테두리 / 우 실선 + 그림자 | 상태(미완성)를 스타일로 드러냄 |
| 시각 무게 편중 | 좌 거대한 흰 면, 우 다크 버튼 1개가 유일한 무게 | 우측에 이미지(표지) 없음 |
| 컨트롤 과대 | 44px 원 버튼 2개 + 점 4개가 콘텐츠 없는 카드 아래에서 도드라짐 | 컨트롤 크기 계층 부재 |
| 블록 헤더 불완전 | 오렌지 kicker만 있고 제목·리드 없음 | 블록 헤더 규칙 부재 |
| 목적 혼재 | 읽을거리(카드뉴스)와 다운로드(소개서)가 한 행 | 블록을 '사용자 행동' 기준이 아닌 '자료 종류'로 묶음 |

**결론:** 이 블록 하나의 문제가 아니라 **밸런스 규칙이 없어서** 생긴 현상. 다른 블록에도 같은 유형이 있을 가능성이 높음 (§3 예상 목록). 규칙을 먼저 세우고 모든 블록에 적용한다.

## 1. B안 방향성

### 1-1. 북극성
> **"홈 첫 장에서 알리고, 콘텐츠 솔루션 안에서 3분 안에 알고, 고르고, 신청한다."**

### 1-2. 디자인 원칙 5가지

| 원칙 | 의미 | 판단 기준 |
|---|---|---|
| 정돈된 신뢰 | 법정교육은 '정확함'이 브랜드. 화면도 정확해 보여야 함 | 정렬선, 높이, 간격이 어긋난 곳 0 |
| 완성된 것만 보인다 | 미완성 자리표시는 신뢰를 깎음 | 배포본에 자리표시 0 (데이터 없으면 블록 비노출) |
| 행동 단위 구성 | 블록 = 사용자가 하는 일 1개 | 블록마다 주 행동 1개, 1차 버튼 1개 |
| 같은 문법 반복 | 모든 블록이 같은 헤더·카드·간격 문법 | 컴포넌트 변형 최소화 |
| 적게, 그러나 깊게 | 허브는 /content 안의 한 축. 다른 축보다 지나치게 길면 안 됨 | 높이 예산 준수 (§2-6) |

### 1-3. 사용자 여정 (5단)

| 단계 | 사용자 질문 | 화면 |
|---|---|---|
| 알림 | 올해 법정교육 준비해야 하는데? | 홈 히어로 1번 슬라이드 |
| 이해 | 우리 회사는 뭘 받아야 하지? | 허브 헤더 + 진단 |
| 선택 | 어떤 과정이 있고 내용은? | 과정 7개 + 상세 |
| 확신 | 법적으로 맞나? 왜 KG에듀원? | 법정 기준 + KG에듀원 차이 |
| 실행 | 어떻게 신청하고 자료는? | 도입 절차 + 자료 + 빠른 상담 |

## 2. 밸런스 규칙 (B안 전체 적용)

'밸런스'를 감이 아니라 **측정 가능한 규칙**으로 정의한다.

### 2-1. 그리드
- 콘텐츠 폭은 /content 기존 `.wrap` 기준 12열
- 허용 분할만 사용: `12` / `6+6` / `5+7` / `4+8` / `4+4+4` / `3+3+3+3`
- **고정 px 열 금지** (예: 420px). 최대 폭 제한은 요소 내부(이미지·카드뉴스 1장)에만
- 880 이하는 모두 1열 또는 2열로 단순화

### 2-2. 행 짝맞춤 (R1)
- 같은 행에 놓인 형제 요소는 **높이를 맞춘다** (stretch)
- 내용 차이로 높이 차가 20% 이상 나는 조합은 **같은 행에 두지 않는다** → 위아래로 분리
- 높이를 맞출 때 짧은 쪽을 빈 여백으로 늘리지 않고, 내용(이미지·요약·보조 정보)으로 채운다

### 2-3. 면적과 정보량 비례 (R2)
- 요소 면적 순위 = 정보 중요도 순위
- 행 안의 빈 공간(콘텐츠 없는 여백)은 행 면적의 15% 이하

### 2-4. 자리표시 금지 (R3)
- 실제 콘텐츠가 없는 요소는 배포본에서 **블록째 비노출** (데이터 배열이 비면 렌더하지 않음)
- 점선 테두리, '예정', '준비 중' 문구 금지

### 2-5. 같은 문법 (R4~R7)

| 규칙 | 내용 |
|---|---|
| R4 블록 헤더 | 모든 블록: kicker(오렌지 선 + 라벨) → 제목(h3, 다른 축과 동일 크기) → 리드 1줄(선택). kicker만 단독 사용 금지 |
| R5 카드 | 1종만: 흰 배경, --line 1px, shadow-1, --r. 강조 카드는 P4 옅은 배경 1종 |
| R6 간격 | 블록 사이 간격 1종, 헤더와 본문 사이 1종, 카드 사이 1종 (기존 토큰에서 선택, 새 값 금지) |
| R7 시각 무게 | 한 행에 무게 중심 1곳 (이미지, 다크 면, P4 채움 버튼 중 하나) |

### 2-6. 높이 예산 (R8)
- 1440×900에서 /content 다른 5개 축 높이 중앙값 = H (실측)
- 허브 전체 ≤ H × 3, 블록 1개 ≤ 900px (과정 그리드만 예외)
- 390에서 블록 1개 ≤ 2화면 (과정 그리드 예외)

### 2-7. 컨트롤 계층 (R9)
- 캐러셀·펼치기 컨트롤은 콘텐츠보다 시각적으로 약하게 (터치 영역 44px는 유지하되 보이는 크기는 작게)
- 점 표시 대신 `1 / 4` 숫자 표시 (점은 위치 정보가 약하고 터치 불가)

## 3. 블록별 현황과 재설계

현재 허브 9블록에 규칙을 대입한 결과. ◯ 적합 / △ 조정 / ✕ 재설계. '예상'은 캡처 실측으로 확정할 항목.

| 블록 | 판정 | 문제 (예상 포함) | 처리 |
|---|---|---|---|
| 헤더 | △ | 다른 축과 문법 동일한지 확인 필요 | R4 통일, 빠른 실행 3개 |
| 진단 | △ | 선택 전 결과 패널이 안내 문구뿐인 빈 면 (예상) | 빈 상태 대신 **기본 추천(공통 2과정)** 을 처음부터 표시 |
| 과정 7개 | △ | 4열에서 7개 → 마지막 행 1칸 빔 | **8번째 타일 '맞춤 구성 상담'** 으로 행 채움 |
| 법정 기준 표 | ◯ | 표 자체는 적합 | 전폭 유지 |
| 운영 지원 | ✕ | 확인된 항목 2개만 → 넓은 행에 카드 2장, 성긴 면 (예상) | 독립 블록 폐지, '차이' 카드로 흡수 |
| 차별점 표 + 시리즈 | △ | 표가 길고 무거움 (예상) | 카드 3장 행으로 요약, 비교표는 펼치기 |
| 자료 | ✕ | §0 사례 | 재설계 (§3-6) |
| 문의 폼 | ✕ | 좌 다크 패널 짧고 우 폼 김 → R1 위반 (예상), 페이지 하단 상담 폼과 중복 | 짧은 빠른 상담 폼으로 교체 (§3-7) |
| 선택 바 | ◯ | | CTA 문구만 조정 |

### 3-1. 새 허브 구성 (9블록 → 6블록)

| 순서 | 블록 | 레이아웃 | 주 행동 |
|---|---|---|---|
| 1 | 헤더 | 12 | 빠른 실행 3개 중 선택 |
| 2 | 진단 | 5+7 (문항 / 추천 결과), 높이 맞춤 | 추천 과정 모두 담기 |
| 3 | 과정 | 3+3+3+3 (7과정 + 상담 타일) | 담기 / 자세히 |
| 4 | 법정 기준과 KG에듀원 차이 | 표 12 → 아래 카드 4+4+4 | 비교표 펼치기 (보조) |
| 5 | 도입 절차와 자료 | 절차 3+3+3+3 → 아래 자료 (§3-6) | 과정소개서 받기 |
| 6 | 빠른 상담 | 5+7 (안내 패널 / 짧은 폼), 높이 맞춤 | 상담 신청 |
| 공통 | 선택 바 | 하단 고정 | 빠른 상담으로 이동 |

### 3-2. 헤더
- 다른 축의 AxHead와 완전히 같은 문법 (번호, kicker, 제목, 리드)
- 제목: `필수 기준은 정확하게, 콘텐츠는 매년 새롭게`
- 리드: `2026년 법정필수교육 7개 과정을 확인하고 바로 상담을 신청하세요.`
- 빠른 실행: `필요 과정 찾기` / `과정 보기` / `빠른 상담` (같은 크기 보조 버튼 3개)

### 3-3. 진단
- 5+7, 두 칸 높이 동일
- 좌: 3문항 (칩)
- 우: 추천 결과
  - **초기부터 채워진 상태**: `모든 기업 공통` 2과정(성희롱 예방, 장애인 인식개선)을 기본 표시
  - 문항 선택에 따라 추가·변경, 변경된 과정만 짧게 강조
  - 하단: `추천 과정 모두 담기` (이 블록의 유일한 1차 버튼)
- 빈 안내 문구만 있는 상태 제거 → R2·R3 충족

### 3-4. 과정
- 1041 이상 4열: 과정 7개 + **상담 타일 1개** = 2행 꽉 참
- 상담 타일: P4 옅은 배경 카드, `찾는 과정이 없나요?` / `기업 상황에 맞춰 과정을 구성해 드립니다.` / `맞춤 구성 상담`
- 폭별 칸 채움

| 폭 | 열 | 구성 |
|---|---|---|
| 1041 이상 | 4 | 7 + 상담 1 = 8칸 |
| 881~1040 | 3 | 7 + 상담 타일 2칸 폭 = 9칸 |
| 561~880 | 2 | 7 + 상담 1 = 8칸 |
| 560 이하 | 1 | 7 + 상담 1 |

### 3-5. 법정 기준과 KG에듀원 차이
- 위: 법정 기준 표 (12열 전폭, 현행 데이터·기준일·출처 유지)
- 아래: 차이 카드 3장 (4+4+4, 높이 동일)

| 카드 | 제목 | 내용 |
|---|---|---|
| 1 | 매년 새로운 시리즈 | 2024 뿅뿅 직장 오락실 → 2025 법정마불 → 2026 법정 헌터스 (미니 타임라인) |
| 2 | 몰입형 스토리 콘텐츠 | 차별점 표 핵심 1줄 + `비교표 보기` 펼치기 (기본 닫힘) |
| 3 | 전담 운영 지원 | 정·부 운영자 배정, 월 1회 이상 방문 (확인된 2개만) |

- 운영 지원 독립 블록 폐지 → 항목 2개뿐인 성긴 행 제거
- 640 이하: 표는 카드형(현행), 차이 카드 1열

### 3-6. 도입 절차와 자료 (§0 사례 해결)

**위: 도입 절차 4단계** (3+3+3+3, 연결선)
- `과정 선택` → `상담 신청` → `구성 확정` → `교육 운영`
- 숫자 번호 대신 아이콘 + 연결선. 문구는 확인된 사실만

**아래: 자료** (행동 기준으로 재구성)

| 상태 | 배치 |
|---|---|
| 카드뉴스 최종본 도착 전 | 카드뉴스 행 **비노출**. 과정소개서 배너만 12열 |
| 카드뉴스 도착 후 | 카드뉴스 4장 행 (3+3+3+3) → 아래 과정소개서 배너 12열 |

- **카드뉴스 4장 행**
  - 1041 이상: 4장을 한 줄에 **모두 노출** (4:5, 각 약 260px 폭). 캐러셀 불필요
  - 클릭 시 확대 보기(라이트박스, 좌우 이동, `1 / 4`, ESC)
  - 881~1040: 4열 유지 / 561~880: 2×2 / 560 이하: 가로 스와이프 (다음 장이 살짝 보이게), `1 / 4` 표시
  - 4장이 같은 높이로 한 줄 → R1·R2 자연 충족, 자동 넘김 문제 없음
- **과정소개서 배너** (12열, 4+8)
  - 좌 4: PDF 표지 목업 이미지 (소개서 1쪽 렌더, 약간 기울임 없음, shadow-2)
  - 우 8: 제목 `2026 법정필수교육 과정소개서` / 설명 1줄 / 담긴 내용 3개 (과정 구성, 학습 목표, 강사 정보) / `과정소개서 받기` (다크 버튼) / 보조 `PDF · 7개 과정`
  - 표지 이미지가 무게 중심, 우측 텍스트와 높이 자연 일치
- 결과: 빈 면 0, 폭 기준 통일, 카드 스타일 1종

### 3-7. 빠른 상담 (허브 마지막)
- 5+7, 두 칸 높이 동일
- 좌 5: 다크 안내 패널 (허브 유일한 다크 면)
  - `매년 받는 법정교육,` / `KG에듀원에서 한 번에 관리하세요`
  - `선택하신 과정을 기준으로 담당자가 영업일 1일 내 연락드립니다.`
  - 하단: 담은 과정 칩 요약 (선택 상태 연동)
- 우 7: 짧은 폼
  - 회사·기관명, 담당자명, 연락처, 이메일, 희망과정(담은 과정 자동 체크), 동의
  - 직급/직책은 운영 필수면 포함 (실측 후 결정)
  - 문의 내용은 1칸 선택
  - 긴 추가 정보 접기 영역 제거 → 폼 높이가 좌측 패널과 맞음
- 모든 진입점(홈 히어로 `빠른 상담`, 헤더, 상세 패널, 상담 타일, 선택 바)은 이 폼으로 이동 + 첫 입력 칸 포커스
- /content 하단 기존 '교육 상담'은 상세 문의용으로 그대로 (허브는 짧은 폼, 하단은 긴 폼으로 역할 구분)
- upgrade-01의 '모달 시트' 안은 철회: 화면 전환이 늘고, 허브 끝 짧은 폼이 밸런스와 흐름 모두에 유리

## 4. 비주얼 언어

### 4-1. 이미지 사용 지도 (이 외 추가 금지)

| 위치 | 이미지 | 비율 |
|---|---|---|
| 홈 히어로 1번 | 실사 (Unsplash 또는 사내 촬영) | 기존 히어로 |
| 과정 카드 7개 | 과정 썸네일 | 16:9 |
| 카드뉴스 4장 | 디자이너 제작 | 4:5 |
| 과정소개서 배너 | PDF 표지 목업 | 3:4 |

- 허브 헤더 이미지는 두지 않음 (다른 축 헤더와 문법 통일)
- 실사 기준: 얼굴 비식별 컷 우선, 자연광·중립 톤, 카드뉴스와 보정 통일, 출처 기록 (upgrade-01 §3-3 유지)

### 4-2. 컬러 역할
- Royal Purple 계열(ink): 제목·본문·다크 면
- P4 오렌지: kicker 선, 담기 상태, 선택 바 카운트, 상담 타일 옅은 배경. **P4 면 위 글자·아이콘은 --ink**
- 다크 면: 허브에서 빠른 상담 패널 1곳, 다크 버튼은 블록당 1개

### 4-3. 아이콘
- 인라인 SVG, 24px 격자, stroke 1.5, 라운드 캡으로 통일
- iconscout·flaticon·icons8은 형태 아이디어 참고만 (라이선스·표기 의무, 세트 혼용 방지)
- 필요 목록: 선택(체크리스트), 신청(말풍선), 확정(달력), 운영(사람+모니터), 다운로드, 시리즈(새로고침), 법정 기준(방패)

### 4-4. 모션
- 등장 페이드 240ms, 담기 전환 240ms, 라이트박스 열림 200ms
- 바운스·1초 초과 금지, reduced-motion 시 즉시 전환

## 6. 밸런스 검수 체크리스트 (디자인 QA)

자동 측정 가능 항목은 검증 스크립트에 포함.

| 항목 | 기준 | 측정 |

| 자리표시 | 0 (점선, '예정', '준비 중') | 자동 |

| 블록 헤더 문법 | 전 블록 kicker + 제목 | 자동 |

| 다크 면 수 | 허브 1 | 자동 |
| 그리드 마지막 행 | 빈 칸 0 (4·3·2열 전부) | 자동 |
| 높이 예산 | 허브 ≤ H×3 | 자동 |
| 시각 검수 | 1440, 1040, 880, 390 캡처를 나란히 놓고 정렬선 확인 | 수동 |
