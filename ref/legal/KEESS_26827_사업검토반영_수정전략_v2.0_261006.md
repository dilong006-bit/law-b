## 4. 예상 교육인원 (#69) 상세

### 현행 실측
- 공유 폼(HomeInquiry)에 '예상 교육인원' 선택 필드 이미 존재, 법정 폼은 `HIDDEN=['companySize','trainees','attachment']`로 숨김
- 기존 옵션: 해당없음 / 1~9명 / ~50명 / ~100명 / ~500명 / ~1000명 / 1000명 이상 → 100과 500 사이 공백 (요청 근거 일치)
- 직급/직책 필수 검증이 `['company','name','phone','position']` 하드코딩

### 반영안
- 노출: 법정 폼에서 직급/직책 자리(연락처 옆)에 예상 교육인원 배치 → 2열 행 균형 유지 (회사 규모는 계속 숨김)
- 옵션: '~ 300명'(lte300) 1개를 ~100명과 ~500명 사이에 추가 → 101~300명 구간 확보
  - 전 폼 공통 추가 권장 (집계 일관성, /kium '1~9명' 추가 선례와 같은 방식: 필드 수·페이로드 키 불변)
  - 직접 입력은 비권장 (집계 불가), 정확한 인원은 문의 내용으로 수용
- 필수 여부: 필수 (직급/직책 필수 승계) → 검증 대상 배열을 폼 설정값으로 전환
- 페이로드: jobTitle 키 유지·빈 값, expectedTrainees 값 전송 (스키마 불변)
- 접수 메일: 직급/직책 빈 칸 행 처리 (빈 값이면 행 숨김 또는 '-') 실서비스 템플릿 확인 필요
