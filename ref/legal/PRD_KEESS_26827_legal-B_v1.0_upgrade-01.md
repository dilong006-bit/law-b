## 1. 고도화 배경: 기준 버전(e1adb1f)의 구조적 한계

1. **입구가 약함:** 홈 첫 화면에 법정교육은 작은 공지 알약뿐. 캠페인의 주인공이 아님
2. **분량 과다:** /content 6개 축 중 법정 허브만 9블록. 다른 축(1~2블록) 대비 페이지 균형 붕괴
3. **밸런스 규칙 부재:** 같은 행 요소의 높이·폭 불일치, 빈 자리표시가 가장 큰 면적 (자료 블록: 좌 525px / 우 180px, 우측 약 345px 공백)
4. **상담이 무거움:** 허브 안 긴 폼 + /content 하단 긴 폼. '빠른 상담'이 없음
5. **신청 방법 부재:** 담기 흐름은 있으나 도입이 어떤 순서로 진행되는지 설명 없음
6. **실사 부족:** 텍스트·표 중심. 신뢰를 주는 실사 톤 없음

> "홈 첫 장에서 알리고, 콘텐츠 솔루션 안에서 3분 안에 알고, 고르고, 신청한다."

## 2. 요구사항 분석

### 2-1. 의도 해석

**[R1] 히어로 섹션 제작 (법정의무)**
- 표면 요청: 법정의무 히어로를 만들어 맨 앞에 배치
- 진짜 의도: 시즌 캠페인을 홈 첫 화면의 주인공으로 만들어 인지 확보
- 해결 문제: 공지 알약은 눈에 띄지 않아 진입이 약함
- 성공한 모습: 홈 첫 방문 시 첫 슬라이드가 법정교육, 버튼 2개로 과정·상담 진입

**[R2] 1Depth 신설 안 함**
- 표면 요청: GNB에 '법정필수' 메뉴를 만들지 않음
- 진짜 의도: 사이트 IA를 흔들지 않고 시즌 콘텐츠를 기존 구조 안에서 해결
- 해결 문제: 시즌마다 메뉴가 바뀌는 운영 부담
- 성공한 모습: GNB DOM 변경 0

**[R3] 콘텐츠 솔루션 하위에 관련 내용만 추가**
- 표면 요청: /content 기존 법정 영역에 내용 보강
- 진짜 의도: 콘텐츠 솔루션의 한 축으로서 자연스럽게 강화 (별도 랜딩처럼 비대하지 않게)
- 해결 문제: 허브가 다른 축보다 지나치게 길어 페이지 성격이 바뀜
- 성공한 모습: 허브 높이 ≤ 다른 축 중앙값 × 3

**[R4] 어떤 과정을 어떻게 신청하는지 확인**
- 표면 요청: 과정 목록과 신청 방법 안내
- 진짜 의도: HR 담당자가 내부 보고 전에 '무엇을, 어떤 절차로' 들여오는지 파악
- 해결 문제: 도입 절차가 보이지 않아 상담 전 불안
- 성공한 모습: 과정 7개 + 도입 절차 4단계가 한 흐름에서 보임

**[R5] 쉽고 빠르게 상담 신청**
- 표면 요청: 간단한 상담 신청
- 진짜 의도: 입력 부담을 줄여 전환율을 높임
- 해결 문제: 긴 폼과 접기 영역이 이탈을 유발
- 성공한 모습: 필수 칸만 있는 짧은 폼, 담은 과정 자동 체크, 모든 진입점이 이 폼으로 연결

**[R6] 자료 다운로드**
- 표면 요청: 과정소개서 받기
- 진짜 의도: 내부 보고용 자료를 쉽게 확보
- 해결 문제: 소개서 카드가 작고 시각 무게가 없어 발견성 낮음
- 성공한 모습: 표지 이미지가 있는 소개서 배너, 제출 후 상담 폼 자동 채움 유지

**[R7] 카드뉴스 확인**
- 표면 요청: 카드뉴스 4장을 사이트에서 봄
- 진짜 의도: 짧은 메시지로 필요성을 설득
- 해결 문제: 캐러셀 1장씩 보기, 빈 자리표시 노출
- 성공한 모습: PC에서 4장이 한 줄에 모두 보이고, 누르면 크게 봄. 최종본 전에는 임시 실사로 영역 유지

**[R8] 모든 섹션 밸런스**
- 표면 요청: 섹션 균형을 완벽하게
- 진짜 의도: '정확한 법정교육'이라는 신뢰를 화면의 정돈감으로 전달
- 해결 문제: 높이·폭·스타일 불일치가 미완성 인상을 줌
- 성공한 모습: 밸런스 규칙(§3-3 LB20) 자동 검수 전 항목 통과

### 3-2. 홈

**LB18 홈 히어로 법정 슬라이드 (Must)**
- 시즌 플래그 켜짐 동안 홈 히어로 캐러셀 **1번 슬라이드**. 기존 슬라이드는 한 칸씩 뒤로
- 구성: 태그 `2026 법정필수교육` / 제목 `올해 법정교육,` `한 곳에서 준비하세요` / 설명 1줄 / 1차 `과정 보기` / 2차 `빠른 상담` / 보조 링크 `과정소개서 받기` / 신뢰 1줄 `7개 과정 · 매년 자체 제작 · 전담 운영자 배정`
- 비주얼: 실사 (LB29). 텍스트 좌 / 피사체 우, 좌측 스크림 위 흰 글자
- 동작: 기존 캐러셀 자동 넘김·일시정지·reduced-motion 규칙 그대로
- 완료 조건
  - 첫 로드 시 법정 슬라이드가 보이고 제목·버튼이 360~1440 모든 폭에서 가림 없음
  - 스크림 위 글자 대비 4.5:1 이상 (실측)
  - 시즌 플래그 끄면 홈 DOM이 기준(커밋 8 이전 홈)과 동일

**LB19 홈 정리 (Must)**
- 공지 알약(LB1)과 캠페인 밴드(LB2) **렌더 제거**
- 이유: 히어로와 같은 메시지 중복. 밴드에서 법정 카드를 빼면 인재키움 카드 1장만 남아 균형이 깨짐. 인재키움은 이미 히어로 슬라이드와 '공개교육 일정' 섹션으로 노출됨
- 완료 조건: 홈에 법정 관련 진입점은 히어로 1곳. 홈 블록 수가 B안 착수 전과 같음

### 3-3. 밸런스 시스템

**LB20 밸런스 시스템 (Must)**
허브 전체가 따르는 규칙. 모든 LB21~LB27의 전제.

| 규칙 | 기준 |
|---|---|
| 그리드 | 12열. 허용 분할 `12`, `6+6`, `5+7`, `4+8`, `4+4+4`, `3+3+3+3`. 고정 px 열 금지 |
| 행 짝맞춤 | 같은 행 형제 요소 높이 차 ≤ 5% (stretch). 내용 차이 20% 이상 조합은 같은 행 금지 |
| 빈 공간 | 행 안 콘텐츠 없는 여백 ≤ 행 면적의 15% |
| 자리표시 | 점선 테두리, '예정', '준비 중' 문구 0 |
| 블록 헤더 | kicker + h3 제목 + 리드(선택). 블록 안 하위 묶음은 h4 |
| 카드 | 1종 (흰 배경, --line, shadow-1, --r) + 강조 1종 (P4 옅은 배경) |
| 간격 | 블록 사이 1종, 헤더와 본문 사이 1종, 카드 사이 1종 (기존 토큰) |
| 시각 무게 | 한 행에 무게 중심 1곳, 1차 버튼 블록당 1개, 다크 면 허브 1곳 |
| 높이 예산 | 허브 ≤ H × 3 (H = 다른 5개 축 높이 중앙값, 1440×900), 블록 ≤ 900px (과정 그리드 예외) |
| 그리드 마지막 행 | 4·3·2열 모두 빈 칸 0 |

### 3-4. 허브 재구성

새 순서 (9블록 → 6블록)

|---|---|---|---|
| 1 | 헤더 | LB21 | 12 |
| 2 | 진단 | LB22 | 5+7 |

| 공통 | 선택 바 | LB28 | 하단 고정 |

**LB21 허브 헤더 (Must, LB4 변경)**
- 다른 축 AxHead와 같은 문법
- 리드: `2026년 법정필수교육 7개 과정을 확인하고 바로 상담을 신청하세요.`
- 빠른 실행 3개 (같은 크기 보조 버튼): `필요 과정 찾기` / `과정 보기` / `빠른 상담`
- 기존 내부 탭·시즌 문구 중 중복 요소 제거
- 완료 조건: 헤더 제목·간격이 다른 축 헤더와 계산값 동일

**LB22 진단 기본 추천 (Must, LB5 변경)**
- 5+7, 두 칸 높이 동일
- 결과 패널은 **처음부터 채워진 상태**: 모든 기업 공통 추천(법정 의무 2 + 권고 2)
- 문항에 답할 때마다 결과가 갱신 (부분 응답 허용)
- 안내 1줄: `공통 추천입니다. 3가지 질문에 답하면 우리 회사 기준으로 바뀝니다.` → 3문항 완료 후 `참고용 결과입니다. 정확한 대상은 상담 시 확인해 드립니다.`
- 1차 버튼 `추천 과정 모두 담기` 항상 활성
- 완료 조건: 초기 상태에 빈 안내 문구만 있는 패널 0, 좌우 높이 차 ≤ 5%

**LB23 과정 그리드 (Must, LB6·LB7 변경)**
- 과정 7개 + **맞춤 구성 상담 타일** 1개
  - 타일: P4 옅은 배경, `찾는 과정이 없나요?` / `기업 상황에 맞춰 과정을 구성해 드립니다.` / `맞춤 구성 상담` → 빠른 상담
- 폭별 칸 채움: 4열 7+1 / 3열 7+타일 2칸 폭 / 2열 7+1 / 1열 7+1
- 상세 패널 하단에 `이 과정으로 상담` 추가 (해당 과정 담기 + 빠른 상담 이동)
- 완료 조건: 모든 열 수에서 마지막 행 빈 칸 0, 인라인 상세 삽입 위치가 타일 포함 행 계산에서도 정확

**LB24 법정 기준과 KG에듀원 차이 (Must, LB8 변경, LB9·LB10 흡수)**
- 위: 법정 기준 표 12열 전폭 (데이터·기준일·출처·안내 문구 유지)
- 아래: h4 `KG에듀원 법정교육이 다른 점` + 카드 3장 (4+4+4, 높이 동일)
  - `매년 새로운 시리즈`: 2024 뿅뿅 직장 오락실 → 2025 법정마불 → 2026 법정 헌터스
  - `몰입형 스토리 콘텐츠`: 핵심 1줄 + `비교표 보기` (펼치면 카드 행 아래 12열 전폭으로 비교표)
  - `전담 운영 지원`: 정·부 운영자 배정 / 월 1회 이상 방문 (확인된 2개만)
- 운영 지원·차별점 독립 블록 제거
- 완료 조건: 카드 3장 높이 차 ≤ 5%, 펼침 전후 카드 높이 불변

**LB25 도입 절차 4단계 (Must, 신규)**
- 블록 제목 `신청부터 운영까지 4단계`
- 단계: `과정 선택` 진단이나 과정 카드에서 필요한 과정을 담습니다 / `상담 신청` 담은 과정 그대로 빠른 상담을 신청합니다 / `구성 확정` 담당자가 인원·일정·운영 방식을 함께 정합니다 / `교육 운영` 전담 운영자가 학습 기간 동안 운영을 지원합니다
- 표현: 아이콘 + 연결선. 숫자 번호 금지

**LB26 자료 재설계 (Must, LB11 변경)**

  - 881 이상 4장을 한 줄에 모두 노출 (4:5). 캐러셀 제거

  - 최종본 도착 전: **임시 실사 이미지(LB29)로 영역 유지**. 이미지 확보 실패 시 중립 면(점선·문구 없음)으로 Empty 처리하고 확대 보기 비활성
