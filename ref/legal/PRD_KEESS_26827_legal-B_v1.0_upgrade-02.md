## 1. 고도화 배경: upgrade-01 설계의 한계

1. **자료 블록 가로 갤러리안(LB26)의 약점:** 카드뉴스 4장을 작게 나열하면 이미지 속 글자를 PC에서도 읽기 어렵고, 블록 높이가 커지며(약 620px), 카드뉴스가 과하게 주인공이 됨
2. **짝 관계 없는 배치:** 기존 배포본은 카드뉴스와 소개서를 역할 관계 없이 한 행에 둬 높이 차 219%, 빈 공간 41%
3. **빠른 상담 패널 채움 19%:** 긴 폼 옆 다크 패널이 짧은 문구뿐이라 비어 보임
4. **도입 절차와 자료가 한 블록:** 주 행동(이해 / 자료 확보)이 달라 블록 헤더 1개로 묶기 어려움
5. **히어로 2차 버튼 글자 대비 3.13~3.98:** 텍스트 기준 4.5:1 미달 (upgrade-01 지시 오류, D9로 정정)

> "빈 공간은 줄이는 게 아니라 기능으로 채운다."

## 2. 요구사항 분석

**[R9] 자료 블록 밸런스**
- 표면 요청: 카드뉴스와 과정소개서 영역의 우측 공백 해소
- 진짜 의도: 자료 영역이 미완성처럼 보이지 않고, 카드뉴스와 소개서가 각자 제 역할을 하게
- 해결 문제: 세로형 미디어와 짧은 텍스트 카드의 구조적 높이 불일치
- 성공한 모습: 좌우 높이 차 ≤ 5%, 우측이 카드뉴스 내비게이션과 자료 받기로 채워짐

**[R10] 카드뉴스를 제대로 읽히게**
- 표면 요청: 카드뉴스 확인 가능
- 진짜 의도: 짧은 설득 메시지를 순서대로 전달
- 해결 문제: 점 표시 캐러셀은 위치·내용 정보가 약하고, 작은 썸네일은 판독 불가
- 성공한 모습: 장별 제목 목차로 어느 장이든 바로 이동, 이미지 문구가 HTML로도 존재

**[R11] 상담 패널이 비어 보이지 않게**
- 표면 요청: 모든 섹션 밸런스
- 진짜 의도: 상담 직전 '내가 무엇을 신청하는지' 확신
- 해결 문제: 다크 패널이 장식 문구뿐
- 성공한 모습: 패널이 담은 과정 요약(편집 가능)으로 기능하고, 폼 스크롤 중에도 보임

### 3-2. LB32 카드뉴스 스토리 (Must)
- 레이아웃: 1041 이상 좌 4열 뷰어 / 우 8열(목차 + LB33). 881~1040 좌 5열 / 우 7열. 880 이하 세로
- 뷰어
  - 4:5 이미지 1장, 이전 · `1 / 4` · 다음 (보이는 크기 작게, 터치 44px)
  - 자동 넘김 없음. 이미지 누르면 확대 보기(라이트박스: 이전·다음·`1 / 4`·닫기·ESC·방향키)
  - 880 이하: 가로 스와이프 트랙, 다음 장 일부 노출, 아래 캡션(현재 장 제목 + `1 / 4`)
- 목차 (880 초과에서만)
  - 제목 h4 `카드뉴스로 먼저 보기`
  - 4항목: 장 제목 + 1줄 요약. 현재 장 강조(좌측 P4 세로선, --ink 굵게), 나머지 --muted
  - 누르면 뷰어 전환 (뷰어 조작 시 목차도 동기화)
  - 숫자 번호 표시 없음
  - 881~1040 에서는 요약 줄 숨김, 제목만
- 목차 문구 (카드뉴스 원고 기준)

| 장 | 제목 | 요약 |
|---|---|---|
| 1 | 법정교육, 우리 회사는 몇 개나 끝냈나요? | 매년 챙겨야 할 법정교육을 점검해 보세요 |
| 2 | 교육만 열면 끝일까요? | 대상 선정부터 증빙까지 담당자가 챙길 일 |
| 3 | 2026년 최신 법정필수교육, 한 곳에 모았습니다 | 최신 콘텐츠 · 맞춤 구성 · 운영 지원 |
| 4 | 올해 법정교육, 지금 점검하세요 | 3가지 질문으로 필요한 과정 확인 |

- 이미지: 최종본 전 Unsplash 임시 실사 4장 (핫링크). 로드 실패 시 중립 면, 확대 비활성, 목차는 동작
- 완료 조건
  - 1041 이상, 881~1040: 좌우 높이 차 ≤ 5%, 우측 콘텐츠 채움 ≥ 85%
  - 뷰어·목차·라이트박스 인덱스 3곳 항상 일치
  - 880 이하: 스와이프와 캡션 동기화, 가로 스크롤 검사 예외 영역 지정

### 3-3. LB33 과정소개서 컴팩트 카드 (Must)
- 위치: 자료 블록 우 8열 하단 (880 이하 뷰어 아래)
- 구성: 표지 썸네일(3:4, PDF 1쪽 렌더) / 제목 `2026 법정필수교육 과정소개서` / 담긴 내용 칩 3개(과정 구성, 학습 목표, 강사 정보) / `PDF · 7개 과정` / `과정소개서 받기`(블록 유일 1차 버튼)
- 게이트 모달, 제출 후 자동 채움, 성공 링크(빠른 상담 이동) 기존 유지
- 완료 조건: 카드 안 표지·텍스트 높이 정렬, 880 이하 1열 정상

### 3-4. LB34 요약형 빠른 상담 패널 (Must)
- 레이아웃: 5+7, 좌 다크 패널 / 우 짧은 폼 (폼 사양은 LB27 유지)
- 패널 내용
  - 제목 `매년 받는 법정교육,` `KG에듀원에서 한 번에 관리하세요`
  - 약속 2줄: `영업일 1일 내 담당자가 연락드립니다` / `담은 과정 기준으로 인원·일정에 맞춘 운영 방식을 안내합니다`
  - **담은 과정 요약**: 제목 `담은 과정 N개`, 과정명 + `빼기`(44px) 목록. 폼 희망과정과 같은 선택 상태
  - 0개일 때: `아직 담은 과정이 없습니다.` + `공통 추천 4과정 담기` 보조 버튼 (성희롱 예방, 장애인 인식개선, 직장 내 괴롭힘 예방, 개인정보보호)
- 1041 이상: 패널 내부 sticky (상단 여백 141px)
- 880 이하: 폼 위 요약 바 (`담은 과정 N개` + 칩 한 줄 가로 스크롤)
- 완료 조건
  - 패널 콘텐츠 ≥ 폼 높이의 45% (과정 3개 담은 상태 기준)
  - 폼 스크롤 중 패널 요약이 뷰포트 안 유지
  - 패널 빼기 ↔ 폼 체크 ↔ 카드 담김 ↔ 트레이 4곳 동기화

### 3-5. LB35 도입 절차 독립 블록 (Must)
- 앵커 `#mandatory-process`, BlockHead(kicker `도입 절차`, 제목 `신청부터 운영까지 4단계`)
- 내용은 upgrade-01 LB25 그대로 (4단계, 아이콘 + 연결선, 숫자 없음, 1차 버튼 `빠른 상담 신청`)
- 자료 블록(`#mandatory-resources`)과 분리된 별도 `.lg-block`

### 3-6. LB36 히어로 2차 버튼 대비 (Must)
- 법정 슬라이드 2차 버튼 글자 대비 4.5:1 이상 (D9)
- 새 색·새 변형 금지. 기존 버튼 클래스 중 조건을 만족하는 것 적용
- 1차·2차 버튼 시각 구분 유지
- 완료 조건: 8개 폭 모두 4.5 이상

### 3-7. LB37 짝 설계 검수 (Must, LB30 확장)
- 모든 `[data-balance-row]` 에 `data-pair` 속성(관계 유형)과 `data-height-owner`(높이 결정자) 지정
- 검수 항목 추가
  - 높이 결정자 외 요소가 결정자 높이의 95~105%
  - sticky 예외 행(`data-sticky-summary`)은 채움 대신 '패널 ≥ 폼 45%' + 스크롤 중 가시성
  - 허브 높이 D1 예산 (1440 ≤ 4422, 390 ≤ 7434), 블록 ≤ 900 (과정 그리드 예외)
- 완료 조건: 전 항목 통과, 실패 시 원인 보고

### 3-8. LB38 Iconify 아이콘 시스템 (Must)
- 출처: Iconify (https://iconify.design/) 에서 **단일 세트 1종**만 사용. 기본 선택 **Lucide** (ISC 라이선스, 상업적 사용·수정 자유, 표기 의무 없음, 선형 아이콘 일관성)
  - 대체 후보: Tabler Icons (MIT). 세트 혼용 금지
  - CC BY 등 표기 의무가 있는 세트, 브랜드 로고 세트 사용 금지
- 적용 방식: 빌드 시점 번들 (npm 오프라인 아이콘 데이터). **런타임 Iconify API 호출 금지** (외부 의존·깜빡임·개인정보 요청 방지)
- 규격: 24px 격자, stroke 1.5, 라운드 캡·조인, `currentColor`, 장식용은 `aria-hidden`
- 적용 범위: 허브 전 아이콘 (빠른 실행, 진단, 담기·체크, 상세 패널, 차이 카드, 도입 절차 4종, 자료 뷰어·라이트박스, 소개서 칩, 빠른 상담 패널, 트레이) + 홈 법정 슬라이드
- 기존 허브 인라인 SVG(icons.tsx)는 같은 형태의 Lucide 아이콘으로 교체. 허브 밖 사이트 공통 아이콘은 이번 범위 밖 (변경 금지)
- 완료 조건: 허브 아이콘 출처 100% 단일 세트, 계산 stroke-width 1.5, 네트워크에 api.iconify.design 요청 0, 아이콘 목록·라이선스가 ASSET_SOURCES 에 기록
