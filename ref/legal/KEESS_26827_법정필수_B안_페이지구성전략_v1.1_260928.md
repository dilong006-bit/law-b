- **과태료 열은 1차 오픈에서 제외** (법무 확인 후 추가). 표 아래 문구: `과태료 등 제재 기준은 상담 시 최신 법령으로 안내해 드립니다.`
- 표 하단: `2026년 ○월 기준 · 출처: 찾기쉬운 생활법령정보, 한국장애인고용공단` + `실제 적용 대상은 사업장 여건에 따라 다를 수 있습니다.`
- 반응형: 880 이하 표 열 축소(대상·주기 합침), 640 이하 과정별 카드 (기존 표→카드 전환 패턴 재사용)

### M6. 운영 지원

### M10. 법정 문의

- 레이아웃: 좌 다크 안내 패널 / 우 폼 (기존 HomeInquiry)
- 안내 패널
  - `매년 받는 법정교육,` / `KG에듀원에서 한 번에 관리하세요`
  - `선택하신 과정을 기준으로 담당자가 영업일 1일 내 연락드립니다.`
- 폼
  - 필수: 회사·기관명, 담당자명, 연락처, 이메일, 희망과정
  - `추가 정보 (선택)` 접기: 직급/직책, 회사규모, 예상 교육인원, 문의 내용, 첨부
  - 희망과정: 담은 과정이 체크된 상태로 시작, 수정 가능, 기타 입력
  - 관심 영역 '법정 필수' 자동 선택, 유입 경로 `content-legal`
- 확인 필요: 운영 폼 필수인 직급/직책을 선택으로 낮출 수 있는지. 불가하면 필수 영역에 포함

### M11. 선택 바

- 표시 조건: 담은 과정 1개 이상 + 허브 영역 안
- 내용: `선택 과정 N개` + 담은 과정 칩 요약(최대 2개 + '외 N') + `문의하기`
- 동작: `문의하기` → M10 이동 + 희망과정 동기화 / 칩 영역 탭 → 선택 목록 펼침(빼기 가능)
- PC·태블릿: 허브 하단에 붙는 바 (허브 밖으로 나가면 숨김)
- 모바일: 화면 하단 고정, safe-area 반영
- 충돌 규칙: 선택 바 표시 중에는 맨 위로 버튼을 선택 바 위로 올리고, 인재키움 티저 스낵바는 숨김
- M10 폼이 화면에 보이면 선택 바 숨김 (중복 방지)

## 6. 비주얼·모션 규칙 (B안 전체)

- Design.md 토큰만 사용. 신규 요소(진단, 담기 버튼, 선택 바)는 기존 칩·버튼·카드·패널 조합
- P4 오렌지 사용처: 배지, 담기 상태 테두리·아이콘, 1차 버튼 강조, 선택 바 카운트
- 풀채도 블록: 페이지당 1개 (M10 안내 패널) 유지
- 모션
  - 등장: 기존 `.r` 리빌, 카드 그리드는 stagger
  - 담기: 아이콘 전환 + 테두리 색 전환 240ms, 선택 바 등장 slide-up 280ms
  - 진단 결과: 높이·불투명도 전환 240ms
  - 바운스·1초 초과 금지, reduced-motion 시 전환 없이 즉시 변경
- 숫자(차시, 인원, 선택 개수)는 tabular-nums
