## 1. 고도화 배경

- **대표 피드백:** "텍스트가 너무 많고 텍스트 위주다"
- 기준 버전의 한계
  1. 진단 결과의 핵심인 '법정 의무 / 권고 / 업종별' 구분이 작은 회색 글자
  2. 과정 7개를 글자로만 식별 (칩, 표, 선택 바, 상세 모두)
  3. 차별점 비교표 5행 × 3열이 전부 글자
  4. 과정 상세 소제목·차시 등 구조 정보에 시각 단서 없음
  5. 숫자(7개 과정, 3문항, 4단계)가 문장 속에 묻힘
  6. 블록 리드·안내문 중복

> "아이콘을 늘리는 게 아니라, 읽을 것을 줄이고 볼 것을 만든다."

---

## 2. 요구사항 분석

**[R14] 텍스트 위주 인상 해소**
- 표면 요청: 텍스트가 많으니 아이콘 등 시각 요소 보강
- 진짜 의도: 읽지 않아도 3초 안에 구조와 구분이 보이는 화면, 상용 서비스 수준 인상
- 해결 문제: 모든 정보가 같은 글자 위계로 나열되어 스캔이 어려움
- 성공한 모습: 화면마다 비텍스트 앵커 1개 이상, 과정·구분을 아이콘·색으로 식별, 글자 15% 감소

## 3. 기능 명세

### 3-1. 우선순위
| 우선 | 기능 |
|---|---|
| Must | LB40, LB41, LB42, LB43, LB45, LB46, LB47 |
| Should | LB44 |
| Could | 진단 결과 구분 막대 전환 모션 |
| Won't | 일러스트·3D 그래픽, 아이콘만 있는 라벨, 과정 카드 본문 아이콘(썸네일과 중복) |

### 3-2. LB40 과정 아이덴티티 아이콘 7종 (Must)
- 과정 1개 = Lucide 아이콘 1개 (전략 §2 표). 후보 순서대로 Lucide 에 있는 첫 이름 사용
- 데이터: `LEGAL_COURSES[].icon` 필드 (한 곳에서 정의)
- 사용처 5곳, 모두 같은 아이콘
  1. 진단 결과 칩
  2. 과정 상세 패널 헤더 (과정명 앞)
  3. 법정 기준 표 교육명 (Should, LB44)
  4. 선택 바 펼침 목록
  5. 빠른 상담 요약 목록
- 금지: 경고·위협 아이콘
- 완료 조건: 5곳 아이콘 이름 일치, aria-hidden, 과정 카드 본문에는 없음

### 3-3. LB41 진단 시각화 (Must)
- 문항 라벨 아이콘 (20px): 상시 근로자 수 `users` / 퇴직연금 도입 `piggy-bank` / 업종 `building-2`
- 결과 상단 **요약**
  - `추천` + 큰 숫자 N + `과정` (숫자 28px 800 tabular-nums)
  - 구분 막대 1줄 (높이 8px, 라운드): 의무·권고·업종별 개수 비율. 색은 기존 배지 체계 (의무 P4 / 권고 P4 45% / 업종별 --line)
  - 막대 아래 범례: 별도 범례 없이 그룹 제목 구분 배지(아이콘 + 글자 + 개수)가 막대 색 순서대로 범례를 겸함 (TECHSPEC D26, 커밋 14 정정)
- 결과 그룹 라벨 → **아이콘 배지**: 법정 의무 `shield-check` / 권고 `lightbulb` / 업종별 권장 `briefcase`
- 과정 칩 앞 아이덴티티 아이콘 16px
- 갱신 시 막대 폭 전환 240ms (reduced-motion 즉시)
- 완료 조건: 진단 행 짝 수치 유지 (높이 비 0.95~1.05), 요약 수치 = 칩 개수, 색만으로 구분하지 않음(배지 글자 동반)

### 3-4. LB42 과정 카드·상세 패널 시각 단서 (Must)
- 과정 카드: 차시 앞 `circle-play` 16px (차시 숫자 굵게)
- 상세 패널
  - 헤더 과정명 앞 아이덴티티 아이콘 20px
  - 소제목 앞 아이콘 20px: 이런 분께 `users` / 학습 목표 `target` / 주요 학습 내용 `list-checks` / 강사 `user-round` / 법적 근거 `scale`
  - 학습 목표 목록 간격 확대 (기존 간격 토큰 중 한 단계 위)
- 맞춤 구성 타일: 좌측 아이콘 타일 `puzzle` (I5 규격)
- 완료 조건: 소제목·차시·타일에 아이콘, 본문 문장에는 아이콘 0

### 3-5. LB43 차별점 비교표 시각화 (Must)
- 행 라벨 앞 아이콘 20px

| 행 | 아이콘 |
|---|---|
| 교육 방식 | clapperboard |
| 콘텐츠 기획 | pen-line |
| 최신성 | refresh-cw |
| 학습 경험 | sparkles |
| 맞춤 제작 | settings-2 |

- KG에듀원 열: 셀 앞 `circle-check` 18px (--ink), 글자 굵게 유지
- 일반 법정교육 열: 아이콘 없음, --muted
- 640 이하 카드형에도 같은 규칙
- 완료 조건: 비교표 펼침 전후 차이 카드 높이 불변 유지, 행 높이 일정

### 3-6. LB44 법정 기준 표 시각화 (Should)
- 교육명 셀 앞 아이덴티티 아이콘 18px
- 구분 배지 안 아이콘 16px (의무 shield-check / 권고 lightbulb / 업종별 briefcase), LB41 과 같은 배지 컴포넌트 (커밋 14 정정: 14 → 16, TECHSPEC §4-8·D20)
- 완료 조건: 표 가독성 유지(행 높이 변화 ≤ 4px), 640 이하 카드도 동일

### 3-7. LB45 허브 헤더 수치 스트립 (Must)
- 리드 아래 4칸: `7` 과정 / `3` 문항 진단 / `4` 단계 도입 / `1일` 내 연락
- 숫자 32px 800 tabular-nums --ink, 라벨 13px --muted, 칸 사이 --line 세로선
- 1041 이상 한 줄 / 560 이하 2×2
- 수치는 사실 확인된 값만 (영업일 1일 내 연락은 빠른 상담 패널 약속 문구와 동일 근거)
- 완료 조건: 빠른 실행 버튼과 겹침 없음, 헤더 블록 높이 증가 ≤ 90px (1440)

### 3-8. LB46 텍스트 다이어트 (Must)
- BlockHead 리드 1줄 32자 이내, 제목 반복 금지
- 법적 고지·과정 원문(소개서 기준)은 대상 아님
- 적용 대상: 블록 리드, 보조 안내문, 빈 상태 문구, 반복 안내
- 변경 전후 문구 표를 보고 (사람 승인 전제 없이 적용, 보고로 검토)
- 완료 조건: 허브 보이는 글자 수(예외 제외) 15% 이상 감소

### 3-9. LB47 시각 앵커·아이콘 규칙 검수 (Must)
- 시각 앵커: 1440×900 로 허브를 위에서 아래로 900px 단위 스캔, 각 화면에 비텍스트 앵커(img, .lg-ico-tile, .lg-stat, .lg-dg-bar, .lg-cn-slide) ≥ 1 (커밋 14 정정: TECHSPEC §8 목록과 일치)
- 아이콘 규칙: 한 라벨 요소 안 svg.lg-ico ≤ 1, 문단(p) 안 아이콘 0, 화면당 아이콘 ≤ 24, 아이콘만 있는 버튼은 aria-label 존재
- 과정 아이콘 5곳 일치
- 글자 수 감소율, 밸런스 수치 유지
- 완료 조건: 전 항목 통과
