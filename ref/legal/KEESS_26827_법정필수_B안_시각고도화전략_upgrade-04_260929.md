## 0. 대표 피드백 해석

| 표면 | 진짜 의도 | 판단 기준 |
|---|---|---|
| 텍스트가 많다 | 첫눈에 **읽지 않고도 구조가 보여야** 한다 | 3초 안에 블록의 주제·구분이 파악되는가 |
| 텍스트 위주다 | 시각 앵커(아이콘, 수치, 이미지, 색 구분)가 부족하다 | 화면 한 장(1440×900)마다 비텍스트 앵커가 1개 이상인가 |
| (암묵) | 대표가 보기에 '완성된 상용 서비스' 수준의 인상 | 경쟁사(휴넷, 멀티캠퍼스) 대비 시각 밀도 |

> "아이콘을 늘리는 게 아니라, **읽을 것을 줄이고 볼 것을 만든다**."

- 해법은 아이콘 하나가 아니라 4가지 수단의 조합
  1. **의미 아이콘**: 라벨의 의미를 한눈에 (장식 아이콘 금지)
  2. **수치 강조**: 7개 과정, 3문항, 4단계 같은 숫자를 크게
  3. **색·형태 구분**: 법정 의무 / 권고 / 업종별을 글자 읽기 전에 구분
  4. **텍스트 다이어트**: 리드·보조 문구를 짧게, 중복 제거

## 2. 과정 아이덴티티 아이콘 7종 (핵심 장치)

한 과정 = 한 아이콘. 진단 칩, 과정 상세, 법정 표, 선택 바, 빠른 상담 요약 **어디서나 같은 아이콘**으로 등장 → 글자를 읽지 않아도 과정을 알아봄.

| 과정 | Lucide 아이콘 (후보 순서) | 의미 |
|---|---|---|
| 직장 내 괴롭힘 예방 | heart-handshake → users-round | 존중하는 관계 |
| 성희롱 예방 | shield-user → shield-alert | 보호 |
| 장애인 인식개선 | accessibility | 포용 |
| 윤리경영 | scale | 공정 |
| 퇴직연금 가입자 | piggy-bank | 연금·자산 |
| 개인정보보호·정보보안 | lock-keyhole | 보안 |
| 자금세탁방지 | landmark | 금융 |

- 부정적·위협적 아이콘 금지 (경고 삼각형, 수갑 등)
- 과정 카드는 썸네일이 있으므로 카드 본문에는 넣지 않음 (중복 방지)

## 3. 아이콘 사용 규칙 (남발 방지)

| 규칙 | 내용 |
|---|---|
| I1 의미 전용 | 라벨의 뜻을 전달할 때만. 장식·반복 아이콘 금지 |
| I2 라벨 단위 1개 | 한 라벨·제목·행에 아이콘 최대 1개. 본문 문장 안에는 넣지 않음 |
| I3 글자 동반 | 아이콘이 글자를 대체하지 않음 (아이콘만 있는 버튼은 aria-label 필수) |
| I4 크기 3단 | 16 (배지·칩 안) / 20 (라벨·행) / 24 (아이콘 타일 안) |
| I5 아이콘 타일 | 40×40, 라운드 12, 배경 P4 8% (기존 is-accent 값), 아이콘 --ink. 절차·차이 카드·맞춤 타일에만 |
| I6 색 | 기본 currentColor (--muted 또는 --ink). P4 면 위는 --ink (D9). 색만으로 구분하지 않음 |
| I7 세트 | Lucide 단일 세트, 선 1.5 (D10) |
| I8 밀도 상한 | 1440×900 한 화면 안 아이콘 ≤ 24개 |

## 4. 수치 강조 규칙

| 위치 | 수치 | 형태 |
|---|---|---|
| 허브 헤더 수치 스트립 | 7 / 3 / 4 / 1일 | 숫자 32px 800 tabular-nums + 라벨 13px --muted, 4칸 한 줄 (560 이하 2×2) |
| 진단 결과 요약 | 추천 N과정, 구분별 개수 | 숫자 28px + 구분 막대 (의무 P4 / 권고 P4 45% / 업종별 --line), 막대 아래 범례는 아이콘 배지 |
| 과정 카드 | 차시 | play-circle + 숫자 강조 |

- 수치는 사실 확인된 것만 (7개 과정, 3문항, 4단계, 영업일 1일 내 연락). 가격·과태료 수치 금지 유지
