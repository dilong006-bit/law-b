## 1. 목표

> "과태료로 겁주는 페이지가 아니라, 법적으로 정확하고 담당자 일을 덜어주는 페이지."

### 해결할 문제
1. 법정교육이 /content 6개 축 중 하나로 묻혀 인지되지 않음
2. 방문자가 자기 회사에 어떤 교육이 필요한지 판단하기 어려움
3. 과정 품질을 확인할 수단(상세 정보, 맛보기)이 부족함
4. 문의에 희망 과정이 담기지 않아 영업이 재확인
5. 업계 법령 표기 오류가 흔함 (의무·권고 혼동, 과태료 금액 불일치)

### 성공 기준
| 구분 | 기준 |
|---|---|
| 인지 | 홈 첫 화면(모든 히어로 슬라이드)에서 법정 진입점 노출 |
| 선택 | 진단 또는 카드 담기로 과정 선택 후 문의까지 이어지는 흐름 완결 |
| 전환 | 법정 문의에 희망과정·유입 경로 기록 |
| 신뢰 | 검증되지 않은 법령·운영 주장 노출 0건 |
| 품질 | 기준 9폭 가로 스크롤·겹침·잘림 0, 터치 44px, 접근성 규칙 준수 |

## 2. 사용자와 여정

### 페르소나
- **HR 교육 담당자 (핵심):** 연간 법정교육 이행·증빙 책임, 과정 구성과 운영 부담이 관심사
- **중소기업 경영지원 겸직자:** 필요한 교육 종류부터 모름 → 진단이 가장 필요
- **금융·공공 담당자:** 업종별 교육(자금세탁방지, 윤리경영) 필요

### LB1 홈 히어로 공지 알약 (Must)
- 문구: `2026 법정필수교육` · `과정 보기` + 화살표 아이콘
- 위치: 히어로 상단, **6개 슬라이드 공통 고정** (슬라이드 전환과 무관)
- 링크: /content#mandatory
- 형태: 기존 유리 질감 알약(btn-glass) + P4 점
- 모바일 390px 미만: `2026 법정필수교육` + 화살표로 축약
- 시즌 플래그로 표시/숨김
- Done when: 6개 슬라이드 모두 같은 위치, 슬라이드 제목·태그와 겹침 0, 9폭 정상

### LB2 홈 캠페인 밴드 (Must)
- 위치: 히어로 바로 아래, 인트로 위
- 카드 2장
  - **법정 카드 (주)**
    - 배지 `2026 법정필수교육`
    - 제목 `올해 법정교육, 한 곳에서 준비하세요`
    - 설명 `성희롱 예방부터 자금세탁방지까지 7개 과정. 필요한 과정 진단부터 운영까지 함께합니다.`
    - 1차 `과정 보기` → /content#mandatory / 2차 링크 `과정소개서 받기` → /content#mandatory-resources
    - 시각 요소: 카드뉴스 미니 캐러셀. 재제작본 전에는 과정 썸네일 2×2 모자이크
  - **인재키움 카드 (보조, 구조만)**
    - `인재키움 프리미엄 공개교육` / `정부지원으로 운영되는 공개교육 일정을 확인하세요` / `일정 보기` → /kium?tab=courses&mode=open#courses
- 핵심 메시지는 캐러셀 밖 텍스트로 항상 노출
- Done when: 760/761 전환 정상, 카드 텍스트가 캐러셀 상태와 무관하게 노출

### LB3 /content 진입 강화 (Must)
- 히어로 6축 맵 '법정 헌터스' 타일에 `2026` 배지
- 타일·SubNav 앵커를 #mandatory로 연결 (기존 #ax5 딥링크는 #mandatory로 이동 처리)
- Done when: 3개 진입 경로(홈 알약, 홈 카드, 6축 타일) 모두 허브 헤더에 도착 (고정 헤더에 가리지 않음)

### LB4 허브 헤더 + 내부 탭 (Must)
- 기존 축 헤더 패턴 유지, 제목 `필수 기준은 정확하게, 콘텐츠는 매년 새롭게` (확정 카피)
- 리드 `2026년 법정필수교육 7개 과정을 진단부터 문의까지 한 곳에서 준비하세요.`
- 시즌 문구 `연내 이수 일정을 함께 계획해 드립니다.`
- 내부 탭 칩 4개: `필요 과정 진단` `과정 보기` `법정 기준` `도입 문의`
- Done when: 칩 클릭 시 해당 블록 이동, 모바일 가로 스크롤 칩 정상

### LB5 필요 과정 진단 (Must)
- 3문항 단일 선택 칩: 상시 근로자 수 / 퇴직연금 도입 / 업종
- 3문항 선택 즉시 결과 표시 (버튼 없음)
- 결과 3그룹: 법정 의무 / 권고 / 업종별 권장 + `추천 과정 모두 담기`
- 규칙 (참고용)

| 조건 | 법정 의무 | 권고 | 업종별 권장 |
|---|---|---|---|
| 공통 | 성희롱 예방, 장애인 인식개선 | 직장 내 괴롭힘 예방, 개인정보보호 | |
| 퇴직연금 도입함·잘 모름 | + 퇴직연금 가입자 | | |
| 금융 | | | 자금세탁방지 |
| 공공기관 | | | 윤리경영 |
| 일반 기업 | | | 윤리경영 |

- 10인 미만 선택 시 안내 `사업장 규모에 따라 교육 방식이 달라질 수 있습니다.`
- 필수 안내 `참고용 결과입니다. 정확한 대상은 상담 시 확인해 드립니다.`
- Done when: 27개 조합 모두 규칙대로 결과 표시, 모두 담기 후 선택 상태 반영

### LB6 과정 라인업 (Must)
- 과정 7개 카드, 순서: 괴롭힘 → 성희롱 → 장애인 → 윤리경영 → 퇴직연금 → 개인정보 → 자금세탁
- 카드: 16:9 썸네일, 담기 버튼(우상단), 구분 배지, 차시, 과정명, 대상·주기(검증된 과정만), `자세히 보기`, `맛보기 ↗`
- 구분 배지 (문구로 구분)

| 배지 | 과정 |
|---|---|
| 법정 의무 | 성희롱 예방, 장애인 인식개선, 퇴직연금 가입자 |
| 권고 | 직장 내 괴롭힘 예방, 개인정보보호 |
| 업종별 | 자금세탁방지 (금융), 윤리경영 (공공·기업) |

- 차시: 괴롭힘 2 / 성희롱 2 / 장애인 2 / 윤리경영 2 / 퇴직연금 3 / 개인정보 4 / 자금세탁 12
- 도구 줄: 필터 칩 `전체` `법정 의무` `권고` `업종별` + `법정 의무 과정 한 번에 담기`
- 맛보기: 캠퍼스21 과정 소개 페이지 새 탭 (noopener)
- Done when: 담기 상태 시각·보조기술 표시, 필터 동작, 7개 맛보기 링크 정상

### LB7 과정 상세 패널 (Must)
- /kium 방식 재사용: PC·태블릿은 **해당 카드 행 아래 인라인 펼침**, 모바일은 **바텀시트**
- 내용: 헤더(썸네일·배지·과정명·차시), 이런 분께, 학습 목표, 주요 학습 내용, 강사, 법적 근거(해당 과정만)
- 하단: `담기`(1차) / `맛보기 보기 ↗`
- 이전/다음 과정 이동
- 교육비 미표기, 성희롱 과정 '주요 학습 내용'은 원본 오기재로 비표시(수정본 수령 시 추가)
- 자금세탁방지 '주요 학습 내용'은 원본 미기재로 비표시
- Done when: 키보드로 열기·닫기·이동, 포커스 복귀, 바텀시트 스크롤 관통 없음

### LB8 법령 기준 (Must)
- 열: 교육명 / 구분 / 근거 / 대상 / 주기 (**과태료 열 없음**)
- 데이터: 기존 AX5.laws 5종 + 윤리경영·자금세탁(근거 미기재, 구분만)
- 괴롭힘 예방: 구분 `권고`로 표기 (기존 운영 표기 '의무'와 다름, 법무 확인 대상)
- 하단: 기준일·출처, `실제 적용 대상은 사업장 여건에 따라 다를 수 있습니다.`, `과태료 등 제재 기준은 상담 시 최신 법령으로 안내해 드립니다.`
- 반응형: 640 이하 과정별 카드
- Done when: 과태료·미검증 수치 0건

### LB9 운영 지원 (Should)
- 제목 `교육은 저희가 운영하고, 담당자는 결과만 확인하세요`
- 카드: `전담 운영자 정·부 2명 지정`, `월 1회 이상 방문 관리` (소개자료 근거)
- `이수 현황·수료증 관리`, `미이수자 학습 독려`는 데이터에 두되 **확인 전 비표시 플래그**
- Done when: 비표시 항목이 화면·HTML에 노출되지 않음

### LB10 차별점·시리즈 (Should)
- 시리즈 타임라인: 연도 + 시리즈명만 (외부 작품명 설명 제거), 2026 현재 표시
- 차별점 5행 비교 (기존 데이터), 640 이하 항목별 블록
- Done when: 외부 작품명 0건

### LB11 자료 (Must)
- 좌: 카드뉴스 (허브 내 수동 넘김, 자리 표시 → 재제작본 교체)
- 우: 과정소개서 카드 `2026 법정필수교육 과정소개서` / `과정 구성, 학습 목표, 강사 정보를 PDF로 받아보세요.` / `과정소개서 받기`
- 게이트: 기존 라이트 게이트 (회사·기관, 담당자명, 이메일 + 필수 동의 + 선택 이메일 수신)
- 제출 후: 다운로드 + `담은 과정으로 도입 문의하기` 링크, 입력값을 문의 폼에 자동 채움
- Done when: 다운로드 동작, 문의 폼 자동 채움 확인

### LB12 실무 FAQ (Could)
- 질문 6개 (연도 기준, 중도 입사자, 온라인 인정, 일부 미이수, 이수 증빙, 소규모 사업장)
- 답변 확정 전 블록 전체 비표시 (질문만 노출 금지)

### LB13 선택 바 (Must)
- 조건: 담은 과정 1개 이상 + 허브 영역이 화면에 있을 때 + 문의 폼이 화면에 없을 때
- 내용: `선택 과정 N개` + 과정명 요약(최대 2개 + 외 N) + `문의하기`
- 요약 영역 탭 → 선택 목록 펼침, 개별 빼기
- PC·태블릿: 화면 하단 가운데 떠 있는 바 (최대 폭 720px)
- 모바일: 화면 하단 전체 폭, safe-area
- 충돌: 표시 중 맨 위로 버튼을 바 위로 이동, 인재키움 티저 숨김
- Done when: 4곳(진단·카드·패널·폼) 선택 값 항상 일치, 하단 요소 겹침 0

### LB14 법정 문의 (Must)
- 기존 문의 폼 + law-A 희망과정 필드 재사용
- 좌측 패널 `매년 받는 법정교육,` / `KG에듀원에서 한 번에 관리하세요` / `선택하신 과정을 기준으로 담당자가 영업일 1일 내 연락드립니다.`
- 필수 표시 영역: 회사·기관명, 담당자명, 연락처, 직급/직책, 이메일, 희망과정 (운영 폼 필수 규칙 유지)
- `추가 정보 (선택)` 접기: 회사규모, 예상 교육인원, 문의 내용, 첨부
- 희망과정: 선택 상태와 양방향 연결
- 관심 영역 '법정 필수' 자동 선택, 유입 경로 `content-legal`
- 제출 데이터 구조 불변
- Done when: 홈·/kium 폼 동작·마크업 불변, 법정 폼 검증 케이스 통과

### LB15 반응형 품질 (Must, 전 기능)
- 원 소스, Design.md 브레이크포인트만 (1040/940/880/820/760/740/720/640/560)
- 기준 9폭(1920/1440/1280/1180/1024/820/768/390/360) + 경계 ±1px

### LB16 접근성 (Must)
- 캐러셀: 재생/정지 버튼 상시, 5초 넘는 자동 넘김은 PC에서만, 사용자 조작 후 자동 넘김 중지, 스와이프 대안 버튼, 위치 `n / N`

## 5. UI/UX 원칙

### 디자인 방향
- 다크는 히어로에만. 허브는 P4 틴트 라이트 캔버스
- P4 오렌지 사용처: 배지, 담기 상태, 1차 강조, 선택 개수
- 풀채도 블록 1개: 법정 문의 좌측 패널
- 신규 요소(진단, 담기, 선택 바)는 기존 칩·버튼·카드·패널 조합으로만 구성
- 카피: 존댓말, 선언형, 과장·공포 소구 금지, 느낌표 금지

- 등장: 기존 리빌, 카드 stagger
- 담기: 아이콘·테두리 전환 240ms, 선택 바 등장 280ms, 숫자 전환
- 진단 결과: 높이·불투명도 240ms
- 1초 초과·바운스 금지, reduced-motion 즉시 변경
