## 2. 밸런스 설계 원칙 (upgrade-03 추가)

### 2-1. 짝 설계 규칙 (Pair Design)
같은 행에 두 요소를 둘 때는 **역할 관계**가 있어야 한다.

| 관계 유형 | 예 | 이번 적용 |
|---|---|---|
| 입력 ↔ 결과 | 진단 문항 ↔ 추천 결과 | 진단 블록 |
| 미디어 ↔ 내비게이션 | 카드뉴스 ↔ 장별 목차 | 자료 블록 (신규) |
| 요약 ↔ 실행 | 담은 과정 요약 ↔ 상담 폼 | 빠른 상담 블록 (보강) |
| 근거 ↔ 차별 | 법정 표 ↔ 차이 카드 | 위아래 배치 (같은 행 아님) |

- 관계가 없는 두 요소(예: 카드뉴스 ↔ 소개서만)는 같은 행에 두지 않는다
- 짧은 쪽은 **여백이 아니라 그 관계에 필요한 콘텐츠**로 높이를 맞춘다

### 2-2. 높이 결정자 원칙
- 한 행에는 높이를 결정하는 요소가 1개만 있다 (비율 고정 미디어, 또는 폼)
- 나머지 요소는 `stretch` 로 그 높이를 따르고, 내부는 `flex` 로 분배

| 행 | 높이 결정자 | 따르는 쪽 |
|---|---|---|
| 진단 | 문항 칸 | 결과 칸 |
| 자료 | 카드뉴스 4:5 | 목차 + 소개서 |
| 빠른 상담 | 폼 | 요약 패널 (sticky) |

### 2-3. 긴 폼 옆 패널 예외 (Sticky Summary)
- 폼처럼 내용 길이가 사용자 입력에 따라 변하는 요소 옆 패널은, 채움 비율 대신 **sticky 요약** 패턴을 쓴다 (체크아웃 주문 요약과 같은 원리)
- 패널 내용은 폼을 스크롤하는 동안 화면 안에 머무름 → 시각적으로 비어 보이지 않음
- 검증 기준: 패널 콘텐츠 ≥ 폼 높이의 45%, 스크롤 중 패널 요약이 항상 뷰포트 안

## 4. 자료 블록: 카드뉴스 스토리 (패턴 A 확정)

```
┌──────────────┬──────────────────────────────────────┐
│              │ h4 카드뉴스로 먼저 보기                 │
│   카드뉴스    │ ▎법정교육, 우리 회사는 몇 개나 끝냈나요? │
│   4:5         │   매년 챙겨야 할 법정교육 점검          │
│   (높이 결정)  │  교육만 열면 끝일까요?                 │
│              │  2026년 최신 법정필수교육, 한 곳에      │
│              │  올해 법정교육, 지금 점검하세요         │
│              ├──────────────────────────────────────┤
│  ‹  1 / 4  › │ [표지] 과정소개서 · 담긴 내용 · [받기]   │
└──────────────┴──────────────────────────────────────┘
       4                          8
```

- 좌: 카드뉴스 뷰어 (자동 넘김 없음, 이전·`1 / 4`·다음, 누르면 확대 보기)
- 우 위: 장별 목차 4항목 (제목 + 1줄 요약). 현재 장은 좌측 P4 세로선 + 굵은 --ink. 누르면 좌측 전환
- 우 아래: 과정소개서 가로 카드 (표지 썸네일 + 제목 + 담긴 내용 칩 3 + `과정소개서 받기`)
- 목차 문구는 카드뉴스 원고 기준 HTML 텍스트 → 이미지 글자를 못 읽는 경우의 대안이자 검색 가능 텍스트
- 880 이하: 카드뉴스 1장 스와이프(다음 장 피크) + 현재 장 제목·`1 / 4` 캡션 → 소개서 카드
- 최종본 전: Unsplash 임시 실사 4장 (D6 핫링크). 목차 문구는 최종 원고 그대로

## 5. 빠른 상담 블록: 요약 ↔ 실행

```
┌──────────────────────┬───────────────────────────────┐
│ (다크, sticky)        │ 회사·기관명 / 담당자명           │
│ 매년 받는 법정교육,    │ 연락처 / 직급·직책              │
│ KG에듀원에서 한 번에…  │ 이메일                          │
│ 영업일 1일 내 연락     │ 희망과정 (담은 과정 자동 체크)    │
│ ─ 담은 과정 3개 ─      │ 문의 내용 (선택, 2줄)            │
│ 성희롱 예방      빼기   │ 동의                            │
│ 장애인 인식개선   빼기   │ [상담 신청]                      │
│ 퇴직연금         빼기   │                                │
└──────────────────────┴───────────────────────────────┘
          5                          7
```
- 패널 = **담은 과정 요약 (편집 가능)** + 연락 약속 2줄. 폼 희망과정과 같은 선택 상태
- 담은 과정 0개: `공통 추천 4과정 담기` 보조 버튼 (1차 버튼은 폼 제출 1개 유지)
- 1041 이상 패널 내부 sticky (헤더 72 + SubNav 53 + 16 = 141px 아래)
- 880 이하: 패널을 폼 위 짧은 요약 바로 (담은 과정 칩 한 줄 + 개수)
